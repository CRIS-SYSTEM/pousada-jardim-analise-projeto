\## Descrição



Sistema desktop desenvolvido para auxiliar a Pousada Jardim no controle de estoque por setor, permitindo acompanhar produtos, quantidades disponíveis, movimentações e prazos de validade.



\## Tecnologias utilizadas



\- C# e .NET 10

\- WPF e XAML

\- MySQL

\- MySqlConnector

\- Visual Studio 2026

\- Git e GitHub



\## Funcionalidades



\- Autenticação e gerenciamento de usuários por perfil

\- Cadastro de produtos, categorias e setores

\- Controle de estoque mínimo por produto e setor

\- Movimentações de entrada, saída e transferência

\- Cadastro opcional de lotes e controle de vencimentos

\- Histórico de movimentações

\- Relatórios, filtros combinados e exportações em PDF e CSV

\- Emissão de requisições físicas



\## Como executar



1\. Instalar o .NET 10 SDK e o MySQL.

2\. Configurar o banco de dados compatível com a aplicação.

3\. Configurar o usuário MySQL `app\_estoque` com as permissões necessárias.

4\. Definir a variável de ambiente `MYSQL\_PASSWORD` com a senha local do banco.

5\. Abrir `CadastroProdutoWpf.slnx` no Visual Studio.

6\. Restaurar as dependências e executar a aplicação.



\*\*Observação:\*\* o banco de dados e suas credenciais devem ser configurados antes da execução.
