📖 Sobre o projeto

O sistema Pousada Jardim foi desenvolvido para auxiliar no gerenciamento de estoque de uma pousada, permitindo acompanhar produtos, movimentações, quantidades disponíveis e prazos de validade.

O objetivo é melhorar a organização do estoque, reduzir perdas e facilitar a identificação de produtos disponíveis em cada setor.

🗄️ MySQL: armazenamento dos dados

🔗 MySqlConnector: comunicação com o banco de dados

🧾 Emissão de requisições físicas

🚀 Como executar

Instalar o .NET 10 SDK e o MySQL Server.

Configurar o banco de dados da aplicação.

Criar o usuário MySQL app_estoque com as permissões necessárias.

Configurar a variável de ambiente MYSQL_PASSWORD.

Abrir CadastroProdutoWpf.slnx no Visual Studio.

Restaurar as dependências e executar o projeto.
